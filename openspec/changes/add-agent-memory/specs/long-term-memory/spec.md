## Purpose

跨会话长期记忆：让 Agent 记住用户的身份、偏好、项目背景等关键事实，无需用户每次重复告知。通过 LLM 从对话中自动提取事实，向量化存储，新对话开始时检索相关记忆注入系统提示。

## ADDED Requirements

### Requirement: 对话后自动提取用户事实

每轮对话结束后（异步，不阻塞 SSE 响应），系统 SHALL 调用 LLM 从该轮对话中提取可长期保留的用户事实，包括但不限于：用户姓名/称呼、回答语言偏好、所在项目、技术栈、明确的长期目标。提取的事实 MUST 去重（相同事实不重复存储）。

#### Scenario: 提取用户姓名

- **WHEN** 用户说"我叫张三，以后叫我老张就行"
- **THEN** 异步任务提取出事实："用户称呼为老张"
- **AND** 写入 user_memory 表，关联当前 user_id
- **AND** 该操作不阻塞当前对话响应

#### Scenario: 提取语言偏好

- **WHEN** 用户说"请一直用中文回答"
- **THEN** 事实"用户偏好中文回答"被提取并存储
- **AND** 事实有向量字段（供后续语义检索）

#### Scenario: 去重相同事实

- **WHEN** 用户第二次说"我叫张三"
- **THEN** 系统检测到已存在"用户姓名为张三"的记忆，不重复写入
- **AND** 更新该记忆的最后访问时间

### Requirement: 新对话注入相关长期记忆

新对话开始时（或每轮对话前），系统 SHALL 基于当前用户问题向量化后检索 Top-K 相关长期记忆，注入 Agent 系统提示（如"已知用户信息：称呼=老张；偏好=中文回答"）。注入 MUST 与短期对话历史区分，标注来源为"长期记忆"。

#### Scenario: 跨会话记住用户

- **WHEN** 用户第二天开启新会话问"帮我看下这个报错"
- **THEN** 系统检索到长期记忆"用户称呼为老张""偏好中文回答"
- **AND** Agent 回答时使用"老张"称呼并默认中文
- **AND** 用户无需重复告知身份

#### Scenario: 相关记忆精准检索

- **WHEN** 用户问题涉及"Spring Boot 配置"
- **THEN** 系统优先检索到"用户技术栈=Java/Spring Boot"记忆
- **AND** 不注入无关记忆（如"用户喜欢喝咖啡"）

### Requirement: 长期记忆可管理

用户 SHALL 能通过 API 查看、删除自己的长期记忆。系统 SHALL 在记忆被证明错误时（如用户纠正）支持更新或删除。记忆删除 MUST 软删除（保留审计）或硬删除二选一，需在实现时确定并文档化。

#### Scenario: 用户查看长期记忆

- **WHEN** 用户调用 `GET /api/memory`
- **THEN** 返回该用户的所有长期记忆列表（内容、类型、创建时间、最后访问时间）
- **AND** 不返回其他用户的记忆

#### Scenario: 用户纠正错误记忆

- **WHEN** 用户说"我不叫老张了，叫我张三"
- **THEN** 系统提取新事实"用户称呼为张三"
- **AND** 标记旧事实"用户称呼为老张"为已过时或删除
- **AND** 后续对话使用新称呼

### Requirement: 长期记忆按用户隔离

长期记忆 MUST 按 user_id 严格隔离。用户 MUST NOT 检索到他人的记忆。向量化检索 MUST 限定在当前用户的记忆范围内。

#### Scenario: 跨用户记忆隔离

- **WHEN** 用户 A 发起对话
- **THEN** 长期记忆检索只在用户 A 的记忆集合中进行
- **AND** 绝不检索或注入用户 B 的任何记忆
