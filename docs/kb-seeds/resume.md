- **CyberLoRA（个人项目），AI 个人写真「展示面」生成工具链，负责全流程搭建**

  **框架构建：**Python + SDXL + kohya_ss + diffusers + InstantID + InsightFace + Gradio + Google Colab(T4 GPU)

  **项目描述：** 面向个人用户的 AI 写真生成方案：用户提供 20‑30 张生活照即可训练专属人物 LoRA，批量产出可直接用于微信朋友圈、抖音的高质量人像，覆盖棚拍肖像、商务正装、咖啡厅日常、户外运动、旅行街景等多种人设场景。同时实现 InstantID 免训练路线作为对比方案，并建立人脸相似度评测闭环做数据驱动的路线选型。核心目标是「看不出是 AI 生成的」——在消费级 T4 GPU 的成本约束下，同时满足人物相似度、照片真实感（不出现五官畸形与塑料感）与画面情绪张力三个要求。

  **个人职责：**

  1. 消费级显卡训练方案：编写 Colab Notebook 实现 T4(16GB) 上的端到端训练，通过 fp16 混合精度（T4 Turing 架构仅 fp16 有 Tensor Core 加速，bf16 需 Ampere 及以上）、AdamW8bit 优化器、gradient_checkpointing、cache_latents_to_disk 与 network_dim=32 / alpha=16 的组合把显存压进16GB，并用 no_half_vae 保留 VAE 为 fp32 规避 fp16 下 SDXL 出 NaN 黑图；用 enable_bucket（512~1536）自适应处理不同尺寸的原始照片，使零硬件成本即可完成一次训练
  2. 相似度量化闭环：用 ArcFace 人脸 embedding 余弦相似度把「像不像本人」从主观感受变成可复现数值，并用多 seed 重复评测报均值±标准差而非单张分数（实测 0.792±0.018，且无身份注入的对照组仅‑0.019，证明指标不会误报）；将评测嵌入出图流程，每档权重自动标注相似度并生成「权重 vs 相似度」曲线，看拐点选档而非拍脑袋。开发自动选片脚本（InsightFace pose + 拉普拉斯清晰度 + embedding 去重），把「20‑30 张、覆盖侧脸与多种表情」的选图规范从文档变成自动化工具。
  3. 真实感与过拟合的平衡：过拟合会直接导致五官变形、油腻塑料感这类典型 AI 痕迹，为此建立 LoRA 权重分档策略（远景/背影 0.5~0.65、常规场景 0.7~0.85、特写不超过 0.95）配合负向词抑制畸形与多指，并以 noise_offset=0.1 增强明暗层次、DPM++ 2M Karras / Steps 25‑30 / CFG 7 固化推理参数，形成可复现的出图质量基线。
  4. 免训练 vs LoRA 路线对比：实现 InstantID（ControlNet + IP‑Adapter）免训练方案，单张照片即可保持人物一致性（3 个 seed 均值 0.792±0.018，标准差极小说明出图稳定）；从制作成本、推理速度、相似度上限、场景灵活性四个维度做数据化对比——C 端即时场景选 InstantID，B 端批量场景选 LoRA，用相似度数据做选型依据而非主观判断。
  5. Gradio Web Demo 与工程化交付：搭建三 Tab 可视化面板（数据准备 / 出图 + 相似度 / 评测），管线单例缓存避免重载 6.5GB 底模；将工具链沉淀为「零 GPU 工程化 + Colab 训练 + 本地 MPS 推理」三条可跑路线，配套故障速查表（含 MPS NaN 黑图 / HF 被墙绕行 / ControlNet 双模型等实测坑），他人 clone 后一键可复现；项目设计思路与迭代记录沉淀为 DESIGN.md，实测成品图与评测报告归档于 showcase/。
